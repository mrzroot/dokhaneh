PROJECT WALKTHROUGH

Rehearse a signed multi-mirror release before publishing.

  1. Plan without uploading

    Configure artifact paths and the public key. Load the private key from the designated secret environment variable, not from the repository.

    dokhaneh publish --version 1.2.0 --dry-run

  2. Check the signed result

    Once you have deliberately published a test release, deep verification compares signed manifests and re-hashes each file on the mirrors.

    dokhaneh verify --version 1.2.0 --deep

  3. Separate access from integrity

    Run status from the networks that matter. A reachable mirror is not the same as a verified one.

    dokhaneh status --version 1.2.0
راهنمای عملی پروژه

انتشار امضاشده روی چند آینه را پیش از بارگذاری تمرین کنید.

  1. پیکربندی و برنامهٔ انتشار

    مسیر فایل‌ها و کلید عمومی را تنظیم کنید؛ کلید خصوصی باید در متغیر محرمانهٔ محیط بماند.

    dokhaneh publish --version 1.2.0 --dry-run

  2. راستی‌آزمایی نسخهٔ آزمایشی

    پس از انتشار عمدی نسخهٔ آزمایشی، امضای مانیفست و هش فایل‌های آینه‌ها را بررسی کنید.

    dokhaneh verify --version 1.2.0 --deep

  3. تفکیک دسترسی از صحت فایل

    وضعیت را از شبکهٔ کاربران بررسی کنید؛ در دسترس‌بودن آینه نشانهٔ معتبر بودن فایل نیست.

    dokhaneh status --version 1.2.0
